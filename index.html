Trust, Safety & Security

Built in accordance with Discord Developer Policies and modern data safety standards.

Zero Message Logging

RubberDuck parses incoming messages strictly in volatile memory for activity XP and keywords. Chat text is never stored in persistent databases.

Commands verify Discord permissions natively. Administrative configurations (`/setupdates`, `/updates`) require Manage Server rights.
